# FeDril social video export

This directory contains the approved vertical FeDril cut for LinkedIn and other social-media publishing workflows.

- `fedril-social-30.mp4` — 1080x1920, 30 fps, 30 seconds, H.264 video with AAC narration
- `fedril-social-30.vtt` — optional English WebVTT caption sidecar

The MP4 already contains visible captions. Use the sidecar only when the destination platform supports a separate accessibility caption upload without duplicating the burned-in captions.
