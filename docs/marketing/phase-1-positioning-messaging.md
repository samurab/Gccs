# Phase 1: Positioning And Messaging

Document type: positioning guide for sales calls, website copy, and demo language.

## Positioning Statement

FeDril is a No-CUI compliance readiness workspace for small government contractors that need to replace scattered spreadsheets with source-backed obligations, ownership, evidence metadata, current report artifacts, and audit history.

## Short Version

FeDril helps small GovCon teams organize what applies, assign who owns it, track allowed evidence metadata, and generate readiness workflow artifacts without using the MVP as a CUI repository.

## What FeDril Is

- A compliance management and readiness workflow tool.
- A No-CUI MVP workspace.
- A way to organize contract metadata, attached clauses, source-backed obligations, evidence metadata, reports, and audit history.
- A tool for internal readiness discipline and pilot discovery.

## What FeDril Is Not

- Not a CMMC certification tool.
- Not legal, accounting, labor, or contracting advice.
- Not a government-endorsed system.
- Not a CUI repository in the MVP.
- Not a replacement for a C3PAO, assessor, attorney, CPA, consultant, or contracting officer.

## Message Pillars

| Pillar | Message | Proof path |
| --- | --- | --- |
| Clarity | See what applies and why. | `Obligations` tab -> source, trigger, required action. |
| Ownership | Assign work to people or roles. | `Obligations` tab -> `Assign by`. |
| Evidence discipline | Track allowed evidence metadata without storing prohibited content. | `Evidence` tab -> metadata fields and No-CUI acknowledgement. |
| Reporting | Generate current workflow artifacts from structured data. | `Reports` tab. |
| Auditability | Trace compliance-relevant changes. | `Settings` tab -> `Audit log`. |
