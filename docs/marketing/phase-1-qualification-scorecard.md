# Phase 1: Qualification Scorecard

Document type: prospect scoring tool.

Use this before offering a full demo or pilot.

## Scorecard

Score each item from 0 to 2.

| Criterion | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Specific workflow | Vague compliance interest | General workflow named | Specific contract, CMMC, evidence, or flow-down workflow named |
| Spreadsheet pain | No current tracker | Tracker exists but pain unclear | Spreadsheet/email/shared-drive pain is explicit |
| Buyer urgency | No timing pressure | Useful someday | Active request, review, prime/customer pressure, or internal deadline |
| Internal owner | No owner | Possible owner | Named owner with availability |
| No-CUI fit | Requires real CUI | Unclear data boundary | Can use synthetic, redacted, or non-sensitive data only |
| Evidence metadata fit | No evidence workflow | Evidence exists but not urgent | Evidence exists and is hard to connect to obligations |
| Willingness to pay | Wants free help | Budget unclear | Accepts paid pilot or has buying path |
| Conversion potential | No subscription path | Possible future path | Clear post-pilot conversion decision |

## Decision Rules

| Score | Decision |
| --- | --- |
| 13-16 | Strong fit. Offer pilot scope review. |
| 9-12 | Conditional fit. Continue discovery or run limited demo. |
| 5-8 | Weak fit. Do not offer a paid pilot yet. |
| 0-4 | Disqualify or redirect. |

## Hard Disqualifiers

Disqualify even if the score is high when the prospect:

- Requires real CUI handling in the MVP.
- Requires GCCS to certify compliance.
- Requires legal, accounting, labor, contracting, government, or assessor determinations.
- Cannot identify a pilot owner.
- Requires custom integrations before any value can be proven.
