# Phase 1: Pilot Scope And Success Plan

Document type: internal and customer-facing pilot scope worksheet.

Status: draft. Counsel review required before use as contractual language.

## Pilot Summary

| Field | Value |
| --- | --- |
| Pilot name | 30-Day Guided Readiness Pilot |
| Pilot fee | $750 flat fee |
| Conversion credit | Credited toward first annual subscription if converted within agreed period |
| Duration | 30 calendar days |
| Data posture | No-CUI / synthetic, redacted, or non-sensitive data only |
| Primary owner | Customer to designate |
| FeDril owner | Founder or implementation lead |

## In-Scope Workflow

Select one:

- Contract readiness intake.
- CMMC readiness tracking.
- Evidence metadata organization.
- Subcontractor flow-down readiness.
- Synthetic demo workflow modeled after the customer's process.

## Success Criteria

| Success criterion | Evidence of completion |
| --- | --- |
| No-CUI boundary confirmed | Customer acknowledges No-CUI posture before upload-related workflows. |
| Contract or synthetic workflow configured | Contract metadata exists in `Contracts`. |
| Clauses attached or reviewed | `Attached clauses` contains relevant published clauses or review notes. |
| Obligations reviewed | `Obligations` work queue contains source-backed obligations for the workflow. |
| Owner/status tracking configured | Obligation detail shows owner assignment and workflow status. |
| Evidence metadata linked | `Evidence` metadata is linked to obligations or controls where applicable. |
| Report artifact generated | `Reports` contains Compliance Status, CMMC Readiness, or Evidence Package artifact. |
| Findings session completed | Customer receives conversion recommendation and next-step decision. |

## Week-By-Week Plan

| Week | Activity | Output |
| --- | --- | --- |
| Week 1 | Kickoff, No-CUI confirmation, workflow selection | Pilot scope locked |
| Week 2 | Contract metadata, clause attachment/review, obligation review | Source-backed workflow visible |
| Week 3 | Owner/status updates and evidence metadata setup | Owned readiness workflow |
| Week 4 | Report artifact generation and findings session | Convert, continue, or stop decision |

## Out Of Scope

- Real CUI.
- Classified information.
- ITAR/export-controlled data.
- Sensitive government-furnished information.
- Credentials, payroll, SSNs, health data, sensitive incident details, or unrestricted security logs.
- Legal advice.
- CMMC certification.
- Assessor determinations.
- Custom integrations.
- GovCloud, FedRAMP, SSO, SCIM, or enterprise procurement support.

## End-Of-Pilot Decision

The customer chooses one:

1. Convert to paid subscription.
2. Continue limited discovery by mutual agreement.
3. Stop because the workflow or timing is not a fit.
